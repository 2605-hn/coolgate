# Đêm Ở Vạn Đò — V8.2: Mở rộng bản đồ Chương 2

## Thay đổi
- Mở rộng khu vực bến đò từ một bến nhỏ thành không gian bờ sông rộng hơn.
- Bổ sung nhà vé cũ, miếu nhỏ, nhà hoang, hàng cây, bờ lau, cọc neo và nhánh cầu phụ.
- Kéo dài cầu gỗ chính ra sông; chiếc đò neo ở khu vực cuối cầu.
- Phân tán ba manh mối theo các khu vực: nhà vé, chiếc đò và cầu gỗ.
- Đưa điểm thoát về cuối cầu để khuyến khích người chơi khám phá toàn bản đồ.
- Tăng mật độ sương và cập nhật các vị trí rình rập của thực thể cho không gian mới.
- Bản 2D không thay đổi.

## Chạy game
```bash
npm install
npm start
```
Mở `http://localhost:3000/3d/?chapter=2` sau khi đã mở khóa Chương 2.

## Điều khiển
WASD di chuyển, Shift chạy, chuột nhìn xung quanh, E tương tác, F đèn pin, Esc nhả chuột.
